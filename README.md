# Sécurité de nuit — jumahestudi

Simulation d'agent de sécurité de nuit : la porte (physionomiste) puis la salle (rondes, incidents, baston),
avec un bilan juridique fondé sur le droit français.

## Contenu du dépôt

| Dossier | Quoi |
|---|---|
| `godot/` | **Projet Godot 4** (version en cours de développement) — voir `godot/LISEZMOI.md` |
| `web/index.html` | Version web 3D jouable (carrière, 4 établissements, baston, habitués) — ouvrir dans Chrome |
| `web/version-2d.html` | Première version 2D (cartes + vue du dessus) |

## Lancer la version Godot

1. Installer **Godot 4.3+** (Standard) : https://godotengine.org/download
2. Godot → **Importer** → `godot/project.godot` → **F5**

## Récupérer les mises à jour

Avec **GitHub Desktop** : *Fetch origin* puis *Pull origin*.
